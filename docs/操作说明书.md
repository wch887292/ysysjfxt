## 1. 概述

### 1.1 文档定位

本操作说明书面向**代理商**和**服务商**的日常操作人员，提供系统各项功能的分步操作指引。涵盖 Web 后台与微信小程序两种操作入口，帮助操作人员快速上手。

### 1.2 操作入口

| 入口 | 访问方式 | 适用角色 |
|------|---------|---------|
| **Web 后台** | 浏览器访问管理后台 URL，账号密码登录 | 代理商、服务商 |
| **微信小程序** | 小程序「我的」页面 → 角色对应管理入口 | 代理商、服务商 |

### 1.3 入口进入方式

**Web 后台登录：**
1. 打开浏览器，输入管理后台网址
2. 输入账号（openid 或手机号）和密码
3. 登录成功后自动跳转至角色首页

**微信小程序入口：**
1. 打开微信，搜索并进入本系统小程序
2. 完成微信授权登录
3. 进入「我的」页面（个人中心）
4. 页面根据角色自动显示管理入口：
   - 代理商 → 点击「🏢 代理商管理」
   - 服务商 → 点击「🏥 服务商管理」

> 💡 若「我的」页面未出现管理入口，请确认账号角色是否已由超级管理员正确设置。

### 2.3 积分核销操作

#### 功能入口

- **Web 后台：** 左侧菜单 →「积分核销」(`/agent/write-off`)
- **小程序：** 代理商控制台 →「💳 积分核销」

#### 操作步骤

1. 进入「积分核销」页面
2. 在「用户」下拉框中搜索并选择目标用户
   - 输入昵称或 openid 进行远程搜索
   - 下拉列表显示格式：`昵称（openid）`
3. 输入「核销积分」数量（1 ~ 999,999）
4. 输入「礼品描述」（必填，最多 200 字）
5. 输入「备注」（选填，最多 200 字）
6. 点击「提交核销」按钮
7. 系统弹出确认提示，确认后提交
8. 核销成功后，页面下方显示核销结果卡片，包含：
   - 用户ID
   - 核销积分
   - 核销前余额
   - 核销后余额
   - 核销单号

> 📷 *[截图：积分核销表单]*
> 📷 *[截图：核销成功结果]*

#### 注意事项

- **幂等键防重复核销：** 系统基于用户ID + 5分钟时间窗口自动生成幂等键（格式 `WO_{userId}_{windowNo}`），同一用户在 5 分钟窗口内重复提交不会产生重复核销
- 核销前请**确认用户积分余额**是否充足
- 核销操作不可撤销，请仔细核实积分数量
- 点击「重置」按钮可清空表单和结果

### 2.4 会员转化操作

#### 功能入口

- **Web 后台：** 「名下用户」页面 → 操作列「转化为会员」
- **小程序：** 代理商控制台 →「🎖️ 会员转化」

#### 操作步骤

1. 进入「名下用户」列表
2. 找到需要转化的非会员用户（列表中「是否会员」列显示为「否」）
3. 点击操作列的「转化为会员」按钮
4. 系统弹出「转化为会员」对话框：
   - 显示用户信息（昵称、openid）
   - 可填写「备注」（选填，最多 200 字，建议记录转化原因或线下沟通情况）
5. 点击「确认转化」
6. 系统弹出**二次确认**提示框：「确认为用户「xxx」开通会员？」
7. 点击「确认」完成转化
8. 转化成功后，系统自动发放积分奖励给用户，用户身份变为会员

> 📷 *[截图：会员转化对话框]*
> 📷 *[截图：二次确认弹窗]*

#### 注意事项

- 仅**非会员用户**会显示「转化为会员」按钮
- 转化操作有幂等键保护（格式 `CONV_{userId}_{windowNo}`），5 分钟窗口内不会重复转化
- 请确保已**线下向用户讲解会员权益**后再执行转化
- 转化成功后系统自动发放积分，无需手动操作

### 2.5 内容发布

#### 功能入口

- **Web 后台：** 左侧菜单 →「图文发布」(`/agent/posts`)
- **小程序：** 代理商控制台 →「📢 信息发布」

#### 操作步骤

1. 进入「图文发布」页面
2. 点击右上角「发布图文」按钮
3. 在弹出的对话框中填写：
   - **标题**（必填，最多 100 字）
   - **内容**（必填，最多 2000 字）
   - **图片链接**（选填，可添加多张图片 URL）
   - **公司名称**（选填，最多 100 字）
4. 如需添加图片：点击「+ 添加图片」，输入图片 URL；可添加多张，也可点击「删除」移除
5. 点击「发布」按钮
6. 系统提示「发布成功，等待审核」
7. 发布内容进入待审核状态，需等待管理员在后台审核通过后才正式发布

> 📷 *[截图：发布图文对话框]*
> 📷 *[截图：待审核状态列表]*

#### 查看已发布内容

- 页面列表展示所有已发布的图文，字段包含：标题、公司名称、状态、发布时间
- 可按状态筛选：**待审核**、**已通过**、**已驳回**
- 点击「查看详情」可在右侧抽屉中查看图文完整内容和图片

#### 状态说明

| 状态 | 说明 |
|------|------|
| 待审核 | 刚提交，等待管理员审核 |
| 已通过 | 审核通过，已对名下会员可见 |
| 已驳回 | 审核未通过，需修改后重新提交 |

#### 注意事项

- 图文发布有幂等键保护（格式 `POST_{标题前缀}_{windowNo}`），5 分钟窗口内不会重复发布
- 图片需先上传至服务器获取 URL，再填入图片链接输入框
- 如审核不通过，请根据驳回原因修改后重新发布

### 2.6 拉新拓客

#### 功能入口

- **Web 后台：** 左侧菜单 →「拉新二维码」(`/agent/share-code`)
- **小程序：** 代理商控制台 →「🔗 拉新二维码」

#### 操作步骤

1. 进入「拉新二维码」页面
2. 页面自动加载您的专属分享数据，包含：
   - **二维码**：展示二维码内容（用户扫码注册后自动绑定代理关系）
   - **分享码**：您的专属邀请码
   - **二维码内容**：二维码编码的链接
   - **分享链接**：可直接分享的 URL
   - **已邀请人数**：通过您的分享码注册的用户数量
3. 点击「复制分享码」将分享码复制到剪贴板
4. 点击「复制二维码内容」将二维码链接复制到剪贴板
5. 点击「刷新」可重新获取最新分享数据

> 📷 *[截图：拉新二维码页面]*

#### 分享方式

- **微信分享：** 将分享链接或二维码图片发送给好友
- **线下推广：** 展示二维码供用户扫码注册
- **线上推广：** 将分享码嵌入推广文案

#### 注意事项

- 分享码**长期有效**，可重复使用
- 用户通过您的分享码注册后，自动成为您的名下用户
- 名下用户产生积分核销、礼品兑换等行为后，您将按约定比例获得分润
- 如需重置分享码，请联系管理员
- 请勿通过违规渠道推广，违规用户将取消代理资格

### 2.10 流失预警处理

#### 功能入口

- **Web 后台：** 左侧菜单 →「流失预警」(`/agent/inactive-users`) 或「预警跟进」(`/agent/alerts`)
- **小程序：** 代理商控制台中对应的预警入口

#### 查看不活跃会员列表

1. 进入「流失预警」页面
2. 页面顶部可设置「未活跃天数阈值」（默认 3 天，可设置 1~30 天）
3. 点击「查询」按钮获取列表
4. 列表展示字段：昵称、openid、最后活跃时间、未活跃天数
5. 未活跃天数颜色标识：
   - ≤3 天：灰色（信息标签）
   - 4~7 天：橙色（警告标签）
   - >7 天：红色（危险标签）
6. 右上角显示流失预警用户总数

> 📷 *[截图：流失预警列表]*

#### 标记跟进

1. 在流失预警列表中，找到需要跟进的会员
2. 点击操作列的「标记跟进」按钮
3. 系统自动跳转至「预警跟进」页面，并筛选该用户的预警记录
4. 在「标记跟进」对话框中：
   - 显示用户信息、预警类型、预警原因
   - 填写「跟进结果」（必填，最多 500 字，如"已电话联系，用户表示近期会恢复使用"）
5. 点击「确认跟进」
6. 跟进状态更新为「已跟进」，列表中该记录显示为「已处理」

> 📷 *[截图：标记跟进对话框]*

#### 预警跟进页面

「预警跟进」页面（`/agent/alerts`）独立展示所有预警记录：

- 可按状态筛选：**待跟进**、**已跟进**、**全部**
- 列表字段：用户、预警类型、预警原因、创建时间、状态
- 待跟进记录可点击「标记跟进」
- 已跟进记录显示「已处理」

### 3.3 接待记录

#### 功能入口

- **Web 后台：** 左侧菜单 →「接待记录」(`/service-provider/receptions`)
- **小程序：** 服务商控制台 →「📝 接待记录」

#### 新增接待记录

1. 进入「接待记录」页面
2. 点击「新增接待记录」按钮
3. 在弹出的对话框中填写：
   - **客户ID**（必填）：输入客户的用户ID
   - **接待时间**（必填）：选择日期时间
   - **接待内容**（必填，最多 500 字）：描述本次接待的主要内容
   - **结果**（必填）：从下拉选项中选择
     - **待跟进**：需要后续跟进
     - **已转化**：客户已转化为会员
     - **需跟进**：需要进一步沟通
     - **流失**：客户已流失
4. 点击「确认提交」
5. 系统提示「接待记录创建成功」

> 📷 *[截图：新增接待记录对话框]*

#### 幂等键说明

系统基于客户ID + 接待时间 + 5分钟时间窗口自动生成幂等键（格式 `rcv_{userId}_{windowNo}`），同一客户在同一 5 分钟窗口内重复提交不会产生重复记录。

#### 查看接待记录列表

- 列表展示字段：客户、接待时间、结果、内容摘要、创建时间
- 结果标签颜色：
  - 待跟进 → 橙色
  - 已转化 → 绿色
  - 需跟进 → 蓝色
  - 流失 → 红色
- 点击「查看」可查看接待记录详情

#### 筛选接待记录

- 可按「客户ID」筛选
- 支持分页，可切换每页条数（10/20/50）

> 📷 *[截图：接待记录列表]*

### 3.6 流失预警

#### 功能入口

- **Web 后台：** 左侧菜单 →「流失预警」(`/service-provider/inactive-users`) 或「预警跟进」(`/service-provider/alerts`)
- **小程序：** 服务商控制台 →「🔔 流失预警」

#### 查看不活跃客户列表

1. 进入「流失预警」页面
2. 设置「未活跃阈值（天）」（默认 3 天，可设置 1~30 天）
3. 可输入昵称或 openid 进行搜索
4. 点击「查询」获取列表
5. 列表展示字段：昵称、openid、最后活跃时间、未活跃天数
6. 未活跃天数颜色标识：
   - ≤3 天：灰色
   - 4~7 天：橙色
   - >7 天：红色
7. 操作列提供：**查看详情**、**标记跟进**

> 📷 *[截图：服务商流失预警列表]*

#### 查看客户详情

1. 在流失预警列表中点击「查看详情」
2. 右侧弹出客户详情抽屉，展示完整的客户信息及未活跃天数

#### 标记跟进

1. 在流失预警列表中点击「标记跟进」
2. 系统跳转至「预警跟进」页面，自动筛选该客户的预警记录
3. 点击「标记跟进」按钮
4. 在弹出的对话框中填写：
   - 显示客户信息、预警类型
   - **跟进结果**（必填）：描述跟进情况（如"已电话联系，客户下周到店"）
5. 点击「确认跟进」

> 📷 *[截图：服务商预警跟进对话框]*

#### 预警跟进页面

「预警跟进」页面（`/service-provider/alerts`）独立展示所有预警记录：

- 可按状态筛选：**全部**、**待跟进**、**已跟进**
- 可按客户ID筛选
- 预警类型说明：
  - 未活跃预警：客户超过阈值天数未活跃
  - 流失预警：客户已流失
  - 低活跃预警：客户活跃度明显下降
  - 无接待预警：客户长时间未到店接待
- 已跟进记录可点击「查看详情」查看跟进结果和跟进时间

## 4. 常见问题与排错

### Q1: 积分核销失败

**现象：** 点击「提交核销」后报错

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|---------|
| 用户积分余额不足 | 查看用户当前积分，确认核销数量不大于余额 |
| 用户ID选择错误 | 重新搜索并选择正确的用户 |
| 5分钟内重复提交 | 幂等键保护，等待 5 分钟后重新提交，或核实上次核销是否已成功 |
| 用户已被封禁 | 联系管理员确认用户账号状态 |
| 网络异常 | 检查网络连接，刷新页面后重试 |

---

### Q2: 会员转化失败

**现象：** 点击「确认转化」后报错

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|---------|
| 用户已经是会员 | 检查用户列表中「是否会员」列，已是会员的用户不会显示转化按钮 |
| 用户不属于当前代理商 | 仅可转化名下用户，确认用户是否绑定至当前代理商 |
| 5分钟内重复提交 | 幂等键保护，等待后重试 |
| 二次确认取消 | 在二次确认弹窗中点击「确认」而非「取消」 |

---

### Q3: 内容审核不通过

**现象：** 发布的图文状态显示为「已驳回」

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|---------|
| 内容包含违禁词 | 检查内容是否涉及诊断类、治疗类、效果承诺类、恐吓类等违禁表述，修改后重新提交 |
| 图片链接无效 | 确认填写的图片 URL 是否可正常访问 |
| 内容不完整 | 确保标题和内容已完整填写 |

**建议：** 发布前自查内容，避免使用医疗诊断、治疗承诺等表述，例如"治愈"、"根治"、"100%有效"等。

---

### Q4: 报告查看无权限

**现象：** 查看用户报告时提示无权限

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|---------|
| 用户不属于当前代理商/服务商 | 仅可查看名下用户的报告，确认用户绑定关系 |
| 用户ID输入错误 | 核实用户ID是否正确 |
| 报告尚未生成 | 用户完成问卷后系统自动生成报告，请等待片刻后重试 |
| 账号权限异常 | 联系管理员确认账号角色是否正确 |

---

### Q5: 分润数据延迟

**现象：** 分润列表中的数据与预期不一致

**说明：**

- 分润数据由系统后台自动计算生成，可能存在**短时间延迟**
- 分润来源包括：礼品兑换、积分核销、会员服务等，需用户完成对应行为后才会产生分润
- 「待结算」分润需等待结算周期后变为「已结算」
- 如长时间未更新，请联系管理员核查

---

### Q6: 小程序管理入口不显示

**排查步骤：**

1. 确认账号角色是否为 `agent`（代理商）或 `service_provider`（服务商）
2. 退出小程序后重新登录
3. 进入「我的」页面，确认登录状态是否正常
4. 如仍未显示，联系管理员确认账号角色设置

---

### Q7: 礼品核销码无效

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|---------|
| 兑换码输入错误 | 核对兑换码是否完整、无多余空格 |
| 兑换码已被核销 | 该码已使用过，不可重复核销 |
| 兑换码已过期 | 联系管理员确认兑换码有效期 |
| 兑换码不属于当前代理商 | 确认该兑换码是否由名下用户生成 |

---

### Q8: 网点信息保存失败

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|---------|
| 网点名称为空 | 网点名称为必填项，请填写 |
| 手机号格式错误 | 手机号需为 11 位，格式如 13800000000 |
| 邮箱格式错误 | 邮箱需为标准格式，如 name@example.com |
| 网络异常 | 检查网络连接后重试 |
