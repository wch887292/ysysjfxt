## 1. 系统简介

### 1.1 系统概述

健康饮食积分系统是一个基于**微信小程序**的健康饮食管理与积分奖励平台。系统通过每日饮食打卡、健康评估、课程学习等多种行为帮助用户建立健康饮食习惯，并以积分激励的方式提升用户参与度，积分可兑换健康礼品，形成"健康行为 → 积分奖励 → 礼品兑换"的完整闭环。

### 1.2 核心特色

| 特色 | 说明 |
|------|------|
| **AI食物识别** | 拍照自动识别食物种类，智能给出健康评分，无需手动输入 |
| **个性化AI报告** | 根据个人健康数据与饮食记录，生成专属饮食建议与调理方案 |
| **积分激励体系** | 打卡、签到、学习、拉新多维度积分获取，持续激励健康行为 |
| **适老化设计** | 大字体、高对比度、简洁操作流程，方便中老年用户使用 |
| **隐私保护** | 非实名注册、数据加密存储、隐私可控，充分保障用户数据安全 |

### 1.3 适用人群

本系统面向以下四类角色，不同角色拥有不同的功能权限：

- **普通用户**：使用打卡、评估、课程、积分等C端功能
- **代理商**：管理名下用户、核销积分、发布内容、查看分润
- **服务商**：管理客户、查看报告、记录接待、管理网点
- **管理员**：系统配置、账号管理、内容审核、数据管理

## 2. 角色说明

### 2.1 普通用户

普通用户是系统的核心使用者，主要使用以下C端功能：

- **每日打卡**：记录每餐饮食，获取积分奖励
- **每日签到**：连续签到获取递增积分
- **健康评估**：填写问卷获取个性化AI饮食报告
- **课程学习**：学习健康饮食课程获取积分
- **积分商城**：使用积分兑换健康礼品
- **拉新拓客**：邀请好友注册获取积分奖励
- **荣誉系统**：查看等级与勋章成就

### 2.2 代理商

代理商是系统在区域市场的运营管理者，主要职责包括：

- **用户管理**：查看和管理名下用户信息与行为数据
- **积分核销**：线下核销用户兑换的积分礼品
- **会员转化**：将免费用户引导转化为付费会员
- **内容发布**：发布健康资讯与活动内容
- **拉新拓客**：拓展新用户并获取相应奖励
- **分润查看**：查看自身分润明细与结算情况
- **流失预警**：关注用户活跃度，及时挽回流失用户
- **报告管理**：查看名下用户的健康报告
- **礼品核销**：核销用户兑换的实物礼品

### 2.3 服务商

服务商是线下服务网点的运营方，主要职责包括：

- **客户管理**：管理到店客户信息与健康档案
- **报告查看**：查看客户健康评估报告，提供针对性建议
- **接待记录**：记录每次客户到店接待情况
- **网点管理**：管理服务网点的基本信息与营业状态
- **流失预警**：监测客户活跃度，预防客户流失

### 2.4 管理员

管理员负责系统的整体运营与管理，主要职责包括：

- **仪表盘**：查看系统核心运营数据与趋势
- **账号管理**：管理各角色账号的创建、权限分配与状态
- **用户管理**：查看和管理全平台用户数据
- **系统配置**：配置积分规则、功能开关等系统参数
- **内容审核**：审核用户发布的内容与资讯
- **数据管理**：管理系统核心数据的导入导出与备份

### 2.5 超级管理员

超级管理员拥有**所有权限**，包括管理员全部功能及以下特权：

- 系统初始化配置
- 管理员账号的创建与删除
- 系统关键参数的修改

> ⚠️ 超级管理员仅通过系统初始化创建，不可通过常规流程注册或申请。

## 3. 快速入门

### 3.1 首次使用

首次使用健康饮食积分系统，请按以下步骤操作：

1. **进入小程序**：打开微信，搜索"健康饮食积分"或扫描小程序二维码
2. **微信登录**：点击"微信登录"按钮，授权微信账号快捷登录
3. **隐私授权**：阅读并确认隐私政策与用户协议
4. **进入首页**：登录成功后自动进入系统首页

> 💡 系统采用非实名注册机制，无需填写真实姓名与身份证号即可使用核心功能。

### 3.2 每日打卡流程

系统提供两种打卡方式，可根据个人习惯选择：

#### 图标打卡

适用于快速记录饮食的场景：

1. 在**首页**点击"每日打卡"入口
2. 选择**餐食类型**（早餐 / 午餐 / 晚餐）
3. 从食物图标列表中选择本次食用的食物
4. 点击"提交"完成打卡

#### 拍照打卡

适用于需要AI智能识别的场景：

1. 在**首页**点击"每日打卡"入口
2. 选择**餐食类型**（早餐 / 午餐 / 晚餐）
3. 点击"拍照"按钮，拍摄食物照片
4. 系统自动进行**AI识别**，识别食物种类并给出健康评分
5. 确认识别结果，点击"完成"提交打卡

### 3.3 积分获取与消费

#### 积分获取

| 行为 | 积分 | 说明 |
|------|------|------|
| 每日打卡 | +10~20 | 每日最多3次，遵循饮食计划额外+20 |
| 每日签到 | +5起 | 连续签到有里程碑奖励 |
| 课程学习 | +10 | 进度达80%自动发放 |
| 拉新拓客 | +50~200 | 被推荐人注册+首次评估→50；7天活跃→100；累计2人→200 |

#### 积分消费

| 行为 | 说明 |
|------|------|
| 礼品兑换 | 在积分商城选择礼品，使用积分兑换，获取核销码后到线下门店核销 |

## 4. 功能详解

### 4.1 首页仪表盘

首页是用户进入系统后的核心页面，展示以下信息：

- **用户信息区**：显示头像、昵称、当前等级
- **积分与排名**：实时展示当前积分余额与平台排名
- **核心功能快捷入口**：打卡、签到、评估、课程、商城等一键直达
- **最近餐食上传记录**：快速回顾近期饮食打卡情况

### 4.2 每日打卡

#### 功能概述

每日打卡是系统的核心功能，通过记录每餐饮食帮助用户养成健康饮食习惯。

#### 两种打卡模式

| 模式 | 适用场景 | 特点 |
|------|----------|------|
| 图标打卡 | 快速记录 | 操作简单，选择食物图标即可完成 |
| 拍照打卡 | 精准记录 | AI自动识别食物种类与健康评分 |

#### 打卡规则

- **每日上限**：每日最多可打卡3次（早、中、晚各一次）
- **基础积分**：每次打卡获得10~20积分
- **饮食计划奖励**：若当次打卡遵循了系统推荐的饮食计划，额外获得**+20积分**
- **AI评分**：拍照打卡时，系统自动识别食物并给出健康评分（1~5星）

#### 操作步骤

1. 首页点击"每日打卡"
2. 选择餐食类型（早餐/午餐/晚餐）
3. 选择打卡方式（图标/拍照）
4. 选择食物或拍摄照片
5. 确认提交

### 4.3 每日签到

#### 功能概述

每日签到是获取积分的轻松方式，通过连续签到机制激励用户保持日常活跃。

#### 签到规则

- **基础积分**：每日签到获取5积分
- **连续签到里程碑奖励**：

| 连续签到天数 | 里程碑奖励 |
|--------------|------------|
| 7天 | +10积分 |
| 30天 | +30积分 |
| 100天 | +100积分 |

#### 操作步骤

1. 首页点击"每日签到"
2. 点击签到按钮完成当日签到
3. 系统展示当前连续签到天数与下一次里程碑奖励

### 4.4 健康评估

#### 功能概述

健康评估通过问卷形式收集用户的健康信息，由AI生成个性化的饮食建议报告，帮助用户了解自身健康状况并获得改善方案。

#### 评估流程

1. **填写问卷**：回答健康相关问卷题目（涵盖饮食习惯、身体指标、生活方式等）
2. **AI生成报告**：系统根据问卷数据，由AI自动生成个性化饮食建议报告
3. **查看报告**：查看报告中的饮食评分、问题分析与改善建议
4. **危机钩子**：若报告中发现潜在健康风险，系统将引导用户到线下门店进行专业咨询

#### 会员特权

- **普通用户**：可查看基础评估报告
- **会员用户**：除基础报告外，还可查看**7天调理方案**，获得更详细的饮食调整指导

#### 评估频率

- 每月可享受**1次免费评估**
- 超出次数需通过会员权益或其他方式获取

### 4.5 课程学习

#### 功能概述

系统提供6门健康饮食相关课程，用户通过学习课程获取积分奖励，同时提升健康饮食知识。

#### 课程列表

| 序号 | 课程名称 | 内容概述 |
|------|----------|----------|
| 1 | 均衡饮食入门 | 营养素基础知识与均衡搭配原则 |
| 2 | 减盐减糖实操 | 日常减盐减糖的具体方法与替代方案 |
| 3 | 蔬果摄入指南 | 各类蔬果的营养价值与每日推荐摄入量 |
| 4 | 控制热量小技巧 | 餐饮选择与烹饪方式中的热量控制方法 |
| 5 | 老年人营养要点 | 中老年人特殊营养需求与饮食注意事项 |
| 6 | 三餐定时定量 | 科学安排三餐时间与分量的实用建议 |

#### 学习规则

- 课程以图文/视频形式呈现，用户自主安排学习进度
- 单门课程学习进度达到**80%**时，系统自动发放**10积分**
- 进度可在课程列表页面实时查看

### 4.6 积分商城

#### 功能概述

积分商城是用户消费积分的核心场所，提供多品类健康礼品供用户兑换。

#### 兑换流程

1. 在积分商城浏览可选礼品
2. 选择心仪礼品，点击"兑换"
3. 确认扣除积分，系统生成**核销码**
4. 持核销码前往**线下门店**进行核销
5. 领取实物礼品

#### 功能说明

- **多品类礼品**：涵盖健康食品、养生器材、生活用品等多种品类
- **核销码**：兑换成功后生成唯一核销码，到店出示即可核销
- **兑换历史**：可在"我的兑换"中查看所有兑换记录与核销状态

### 4.7 拉新拓客

#### 功能概述

拉新拓客功能允许用户通过分享邀请好友注册，双方均可获取积分奖励。

#### 拉新规则

| 触发条件 | 推荐人奖励 | 说明 |
|----------|------------|------|
| 被推荐人注册+首次评估 | +50积分 | 好友完成注册并完成首次健康评估 |
| 被推荐人7天真实活跃 | +100积分 | 好友注册后7天内有真实活跃行为（打卡/签到/学习等） |
| 累计拉新2人 | +200积分 | 里程碑奖励，累计成功邀请2人 |

#### 操作步骤

1. 进入"拉新拓客"功能页
2. 点击"生成分享链接"，系统生成专属邀请链接
3. 将链接分享给微信好友或微信群
4. 好友通过链接注册后，系统自动追踪并发放积分

### 4.8 荣誉系统

#### 功能概述

荣誉系统通过等级与勋章双重机制，展示用户在平台上的健康成就。

#### 等级体系

| 等级 | 名称 | 说明 |
|------|------|------|
| 1级 | 健康新人 | 注册默认等级 |
| 2级 | 健康达人 | 达到一定积分与活跃度后晋升 |
| 3级 | 健康之星 | 持续活跃与健康行为积累 |
| 4级 | 健康大使 | 高度活跃，具有影响力 |
| 5级 | 健康使者 | 最高等级，健康生活典范 |

#### 勋章体系

| 勋章名称 | 获取条件 |
|----------|----------|
| 打卡达人 | 累计打卡达到指定次数 |
| 学习标兵 | 完成全部6门课程学习 |

| 签到坚持 | 连续签到达到指定天数 |

> 💡 等级与勋章会在个人主页展示，是健康习惯养成的直观证明。

## 6. 安全与合规

### 6.1 医疗免责声明

本系统提供的健康评估报告与饮食建议**仅供参考**，不构成医疗诊断或治疗建议。如有健康问题，请及时咨询专业医疗机构。

### 6.2 数据加密存储

用户数据采用加密存储机制，关键信息（如健康数据、评估报告）在传输与存储过程中均进行加密处理，防止数据泄露。

### 6.3 隐私授权管理

- 首次使用需确认隐私政策与用户协议
- 用户可随时查看与修改隐私授权范围
- 信息可见性由用户自主控制

### 6.4 违禁词检测

系统内置违禁词库，对用户发布的内容进行自动检测，过滤违规信息，保障平台内容安全。

### 6.5 内容安全审核

所有用户发布的内容均经过审核流程，管理员可对内容进行审核、编辑或下架处理，确保平台内容健康合规。
